# 🏥 Tech.Care Healthcare Dashboard

A responsive healthcare dashboard UI developed using **HTML5 and CSS3**, based on an Adobe XD healthcare dashboard design.

The dashboard displays patient information, diagnosis history, blood pressure data, vital signs, and doctor/patient profile information.

---

## 📌 Project Overview

The **Tech.Care Healthcare Dashboard** is a frontend web application designed to provide healthcare professionals with a simple and visually organized interface for viewing patient information.

The dashboard includes:

- Patient list
- Patient profile
- Diagnosis history
- Blood pressure chart
- Respiratory rate
- Temperature
- Heart rate
- Doctor information
- Navigation menu
- Responsive layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts
- SVG

---

## ✨ Features

### 👨‍⚕️ Patient Management

- Displays a list of patients
- Highlights the currently selected patient
- Shows patient name, gender, and age

### 📊 Diagnosis History

- Blood pressure history
- Systolic and diastolic values
- Six-month diagnosis overview
- Visual graph using SVG

### ❤️ Vital Signs

The dashboard displays:

- Respiratory Rate: **20 bpm**
- Temperature: **98.6°F**
- Heart Rate: **78 bpm**

### 👤 Patient Profile

The profile section contains:

- Patient name
- Date of birth
- Gender
- Contact information
- Emergency contact
- Insurance provider

### 🎨 Responsive Design

The dashboard is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices
